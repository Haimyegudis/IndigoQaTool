# Indigo-AiTools

This repository is a collection of services and utilities built around **Large Language Models (LLMs)**.  
It focuses on developing **MCP-based tools** and creating **AI-powered solutions** that can be used both internally and as part of our software for external clients.  

## Purpose

- Build reusable **MCP services**  
- Develop **LLM-powered solutions** (local models and Azure OpenAI)  
- Provide AI capabilities that can be integrated into our own systems or delivered to external clients  
- Accelerate experimentation and deployment of AI-driven features  

## Planned Contents

- MCP services for common AI workflows  
- Utilities for connecting to local and cloud-based LLMs  
- Ready-to-use AI service components for client applications  
- Examples and best practices for deploying LLM-powered solutions  

## Contributing

This repository is intended for active development of AI services.
